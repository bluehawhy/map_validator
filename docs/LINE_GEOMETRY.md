# 입력툴 2D 선형 ↔ 로드뷰 도로 형태 비교

## 목적과 범위

**도로후보 분석**은 현재 선택된 검수 ID의 저장 폴더에서 `HD_3D Tool`과 `NLadybugSv`의 **이미 저장된 PNG**를 읽고 선형을 비교합니다. 다시 캡처하거나 프로그램의 창·Zoom·로드뷰 시점을 조작하지 않습니다. 결과는 어디까지나 **도로 선형 대조 후보**이며 실제 3D 좌표 정합이나 차선 연결 여부의 확정 판정이 아닙니다.

## 입력툴에서 추출하는 경로

입력툴의 어두운 지도 영역에서 HSV 색상 마스크와 연결 성분을 사용합니다.

- **하늘색**: 지도 경로의 **진입/시작**
- **주황색**: 교차로를 통과하는 **연결 경로**
- **파란색**: 해당 경로의 **진출/끝**

하늘색 끝점에서 주황색 연결선, 이어서 파란색 끝점까지 연결 가능한 후보를 찾습니다. 두 선 사이 거리와 유사한 복수 경로의 존재 여부를 확인하여 불명확하면 `unknown`으로 보류합니다. 진입 벡터와 진출 벡터의 부호 있는 회전각으로 좌회전/우회전/직진 후보를 계산합니다. 다른 색의 일반 도로선이나 주변 경로를 잘못 고를 위험이 있으므로 이미지에 그린 경로를 사람이 반드시 확인해야 합니다.

이 단계는 지도의 **2D 화면에서 보이는 색상 선형을 추적**한 것이며 화면 좌표를 위경도, 실제 도로 방향 또는 3D 세계 좌표로 변환하지 않습니다.

## 로드뷰에서 비교하는 단서

1. 기존 SegFormer 모델로 **도로 마스크**를 추출합니다.
2. 화면 아래 중앙에서 먼 쪽으로 연결되는 도로 영역을 따라 **시각적인 중심 경로**를 표본화하여 좌/우 굽음 후보를 구합니다.
3. 중간 거리의 좌·우 도로 영역 후보를 계산합니다.
4. 입력툴에서 추정한 **진입 → 교차로 → 진출** 방향과 로드뷰 도로 중심 경로·측면 영역 후보를 함께 대조합니다.

로드뷰 카메라 시점, 차량 가림, 도로 폭, 교차로까지 남은 거리와 지도 화면의 회전이 서로 다르기 때문에 **한 장의 화면만으로 실제 3D 선형이 같다고 판정할 수 없습니다**. 정밀 비교에는 지도상의 기준점, 실제 도로 좌표, 카메라 자세·위치 등의 보정 정보가 더 필요합니다.

## 결과 해석

| 상태 | 의미 |
|---|---|
| `geometry_consistent_candidate` | 입력툴의 회전 방향과 로드뷰 중심 경로의 굽음 및 측면 도로 후보가 일치함 |
| `direction_consistent_candidate` | 일부 방향 단서가 일치하지만 정확한 선형 일치는 확인되지 않음 |
| `possible_mismatch_review` | 입력툴 경로와 로드뷰 방향 단서가 충돌할 가능성이 있어 수동 검수 필요 |
| `mixed_evidence_review` | 여러 스크린샷의 대조 결과가 서로 충돌함 |
| `insufficient_evidence` | 색상 경로 검출 부족, 불명확한 연결, 시야 부족 등으로 판정 보류 |

**모든 상태는 반드시 사람이 최종 확인**합니다. 특히 `geometry_consistent_candidate`도 실제 회전 차로의 존재나 교차로 연결 구조가 확정적으로 동일하다는 뜻이 아닙니다. 직진 후보는 현재 데이터만으로 기하학적 일치를 판단하지 않고 보류합니다.

## 저장 산출물

기존 결과 폴더의 원본 이미지는 수정하지 않습니다.

- `<검수 ID>_HD_3D Tool_geometry.png`: 입력툴에서 연결된 색상 선형 후보를 표시한 이미지
- `<검수 ID>_NLadybugSv_overlay.png`: 도로 마스크·좌우 후보·도로 중심 경로·대조 상태가 표시된 이미지
- `analysis.json`: `input_line_geometry`, `roadview_corridor`, `geometry_comparison` 및 전체 상태

파일이 여러 장이면 `_01`, `_02` 등 같은 번호의 입력툴과 로드뷰를 가능한 한 쌍으로 묶습니다. 입력툴 사진이 없거나 색상 연결이 모호하면 대조를 추측하지 않고 보류합니다. `result.json`과 캡처 원본은 그대로 유지합니다.

## 구현 위치

- `map_validator/line_geometry.py`: 입력툴 색상 선형 추출, 좌우 회전각 추정, 후보 비교
- `map_validator/road_shape.py`: 로드뷰 도로 마스크의 중심 경로 추정
- `map_validator/saved_analysis.py`: 같은 검수 ID의 원본 사진 연결, 결과 이미지와 JSON 저장
- `UI/worker.py`: 기존 저장 사진 기반 분석 작업 실행
- `UI/app.py`: 사용자에게 선형 대조 결과 표시

색상 감지는 화면 테마, 확대/축소, 도면 선색 변경에 영향을 받습니다. 실무 사진을 공개 저장소에 업로드하지 말고, 인식 결과에 의문이 있으면 원본과 표시 이미지를 함께 비교하세요.
