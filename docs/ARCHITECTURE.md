# 아키텍처

```text
[Windows 업무 프로그램] -> (버튼 클릭) -> [별도 로드뷰 창]
                                              |
                                          W/S 이동
                                              |
                                          MSS 캡처
                                              |
                                     SegFormer 도로 마스크
                                              |
                                   좌/우 측면 ROI 후보 점수
                                              |
                                증거 PNG + 결과 JSON + 사람 검수
```

## 구현 모듈

- `map_validator/windows.py`: 프로그램 창 탐색/활성화, 이미지 버튼 클릭, 화면 캡처, W/S 이동.
- `map_validator/road_analysis.py`: ADE20K SegFormer 도로 픽셀 분할 및 좌/우 후보 영역 추출.
- `map_validator/cli.py`: 단계 실행, 파일 저장, 검수 JSON 생성.

## 모델과 정확도 경고

초기 도로 영역 모델: `nvidia/segformer-b0-finetuned-ade-512-512`. 도로로 분류된 픽셀이 화면 좌·우에 존재한다고 해서 골목길 연결도로가 있다고 단정할 수 없다. 넓은 본선, 주차장, 곡선, 원근, 차량/건물에 가려진 갈림길이 오류를 만든다. 좌·우회전 유효 여부는 자동 확정하지 않는다.

## 안전 정책

1. 창 제목이 일치하지 않으면 화면 클릭/키 입력을 중지한다.
2. 버튼 이미지 유사도가 임계값보다 낮으면 클릭하지 않는다.
3. 이동 키는 W/S만 허용하고 횟수 및 누름 시간을 제한한다.
4. 기본 동작은 이동 없음; 화면 회전 없음.
5. 불확실한 결과는 확인 필요로 유지한다.
6. 업무 프로그램에 데이터를 자동 저장/수정하지 않는다.

## 추후 연동

업무 프로그램 화면에서 진입 하늘색/진출 파란색/교차점 주황색 선형을 추출해 좌/우 기대값을 구하고, 로드뷰 후보와 비교해 사람이 검수하도록 확장한다. 현재 버전에 자동 비교는 없다.
