# 아키텍처

## 데이터 흐름

```text
[Windows 업무 프로그램]
   └─ 사용자가 교차로 선택 → [로드뷰 열기 버튼 탐색/클릭]
                                ↓
                         [별도 로드뷰 창]
                                ↓ W/S 앞뒤 이동만
                         [시점별 화면 캡처]
                                ↓
             [선택적 도로 영역 분할과 좌·우 후보 표시]
                                ↓
                 [증거 PNG + JSON + 사람의 대조 검수]
```

업무 프로그램의 2D 선형(하늘색 진입, 파란색 진출, 주황색 교차점 연결)은 검수자가 기대하는 방향을 읽는 기준이다. 현재 자동화 흐름은 이 선형을 읽거나 로드뷰와 비교하지 않는다. 사용자가 캡처와 2D 화면을 직접 대조한다.

## 모듈 경계

- `map_validator/windows.py`: Windows 창 검색·활성화, 템플릿 버튼 클릭, W/S 입력, 캡처.
- `map_validator/road_analysis.py`: SegFormer 도로 영역 분할, 좌·우 후보 ROI와 오버레이 산출.
- `map_validator/cli.py`: 옵션 해석, 작업 순서 실행, 이미지 및 JSON 저장.
- `UI/`: PyQt6 제어창, 설정 입력, 백그라운드 실행, 상태·로그 표시. 핵심 자동화 로직은 `map_validator/`를 호출한다.
- `docs/`: 컨셉, 요구사항, 구조, 조작 및 개발 계획.

UI와 CLI는 가능한 한 같은 핵심 모듈을 호출한다. UI 전용 코드를 분석 엔진에 넣지 않는다.

## AI 분석의 의미와 한계

초기 모델은 `nvidia/segformer-b0-finetuned-ade-512-512`다. 모델이 도로로 분류한 픽셀을 바탕으로 화면 좌·우의 후보를 표시한다. 이것은 좌·우회전 차로를 식별하거나, 교차로 연결 여부·회전 가능 여부를 확인하는 모델이 아니다. 주차장, 본선, 곡선, 가림, 원근 때문에 오탐·미탐이 생길 수 있다. 최종 판정은 항상 사람이 한다.

## 조작 안전장치

1. 창 제목이 맞지 않으면 마우스 클릭과 키 입력을 중단한다.
2. 버튼 템플릿 유사도가 기준보다 낮으면 클릭하지 않는다.
3. 이동 입력은 W/S만 허용하고 횟수와 누름 시간을 제한한다.
4. 기본 이동은 없음이며 좌우 시점 회전은 수행하지 않는다.
5. 중지 요청과 PyAutoGUI FAILSAFE를 제공한다.
6. 업무 프로그램에 검수 결과를 자동 입력하거나 저장하지 않는다.

## 확장 순서

먼저 캡처 수집과 사람의 판정이 안정적으로 반복되도록 한다. 이후 별도 합의와 표본 검증을 거쳐 2D 선형 추출 또는 검수 UI를 확장한다. 자동 최종 승인 기능은 범위에 포함하지 않는다.
