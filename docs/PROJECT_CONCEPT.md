# 프로젝트 컨셉

## 프로젝트명

**map_validator** — Windows 업무 프로그램의 교차로 경로를 로드뷰와 대조할 때 검수 과정을 돕는 데스크톱 도구.

## 해결하려는 일

업무 프로그램에는 교차로의 2D 경로가 표시된다. 하늘색 원도로(진입), 파란색 나가는 도로(진출), 주황색 교차점 연결 경로를 참고해, 특히 좌회전·우회전 방향에 필요한 차로 또는 연결 도로가 현장 로드뷰에도 보이는지 확인해야 한다.

검수자는 업무 프로그램에서 지점을 선택하고 로드뷰를 연다. 도구는 별도 로드뷰 창을 캡처하며 W/S로 앞뒤 이동할 수 있다. 여러 시점의 캡처와 도로 영역 후보를 한 검수 건으로 모아, 사용자가 2D 경로와 직접 대조하도록 한다.

## 사용 흐름

1. 업무 프로그램에서 교차로를 열고 로드뷰 버튼을 누른다.
2. map_validator에서 검수 ID와 창/버튼 설정을 확인한다.
3. 로드뷰를 열거나 이미 열린 창을 선택한다.
4. 이동 없음, W 전진, S 후진 중 필요한 동작과 횟수를 지정한다.
5. 캡처 또는 도로 후보 분석을 실행한다.
6. 저장된 캡처와 오버레이를 업무 프로그램의 2D 경로에 대조한다.
7. 검수자가 좌·우회전 차로/연결 도로가 보이는지, 추가 확인이 필요한지 판단한다.

## 범위 원칙

- 키보드 자동 이동은 W/S 앞뒤만 수행하며 화면의 좌우 회전은 하지 않는다.
- 핵심 검수 항목은 좌회전·우회전 방향의 차로 또는 연결 도로가 실제 화면에 보이는지다.
- 직진 차로, 노면 화살표, 차로 수, 교통 규칙은 현재 검수 대상이 아니다.
- AI의 도로 픽셀 분할과 좌·우 후보 표시는 참고자료다. 실제 회전 차로·연결 여부를 판정하지 않는다.
- 2D 선형 자동 추출, 좌우 기대값 계산, 자동 비교는 현재 구현 범위 밖이다.
- 결과 저장은 검수 자료까지다. 업무 프로그램에는 승인·수정값을 자동 입력하지 않는다.
- 모든 결과에 사람이 최종 확인한다.

## 결과물

검수 ID별로 원본 캡처, 선택적 분석 오버레이, JSON 메타데이터를 저장한다. JSON에는 검수 ID, 이동 순서, 분석 상태와 사람 검수 필요 상태가 포함된다. 캡처와 결과는 실무 자료일 수 있으므로 공개 저장소에 추가하지 않는다.

## 성공 기준

- 지정한 업무 프로그램과 로드뷰 창을 안정적으로 찾는다.
- 로드뷰 버튼과 W/S 조작이 설정 범위 안에서 수행된다.
- 각 검수 시점이 다시 확인할 수 있는 이미지와 함께 저장된다.
- AI 후보가 확정 판정처럼 보이지 않고, 검수자가 원본 화면에서 결론을 낼 수 있다.

## 현재와 향후

초기 버전은 창 조작, 캡처, 도로 영역 기반 좌·우 후보 표시, 결과 저장을 제공한다. 다음 개발은 현장 사용에서 필요한 캡처 흐름과 검수 표시를 다듬는 데 집중한다. 2D 경로 인식이나 더 정교한 AI는 실제 표본과 필요성이 확인된 뒤 설계한다.
