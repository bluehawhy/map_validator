# map_validator Windows 제어 UI

참고 UI: https://github.com/bluehawhy/nv_c_test (PyQt6, 작은 반투명 상단 고정창, 드래그 헤더, 상태·로그 표시).

## 실행 조건 및 설치

Windows 11과 설치된 호환 Python을 사용합니다. 3.11이 꼭 필요하지는 않습니다. Python 런처에서 사용할 수 있는 버전은 `py list`로 확인합니다.

```powershell
git clone https://github.com/bluehawhy/map_validator.git
cd map_validator
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements-ui.txt
# AI 분석 시에만 추가 설치
python -m pip install -r requirements-ai.txt
python -m UI
```

또는 `UI\run_ui.bat`을 실행합니다. 실행할 때 `config.yaml`에 없는 항목만 `config.example.yaml`에서 추가하고, 기존에 들어 있는 항목과 값은 그대로 유지한 뒤 UI를 엽니다. `config.yaml`이 없으면 예제 설정으로 새로 만듭니다.

## UI 항목과 작업

- **입력 프로그램 / 로드뷰 프로그램**: 사용자가 프로그램명을 입력한 뒤 **선택** 버튼을 누르면 목록을 띄우지 않고 일치하는 실행 중인 창을 즉시 복원·활성화합니다. `프로그램명 - 워크스페이스명` 형태의 실제 창 제목은 워크스페이스 부분을 제외하고 비교합니다. map_validator UI는 최소화하지 않고 현재 위치에 유지합니다. 프로그램 자체를 실행하거나 초기 설정하지 않습니다.
- **검수 ID**: 좌·우 도로 후보 분석 시작 시 `windows.intersection_review_title`로 지정한 **교차로 선형 검수** 창의 선택 항목을 읽습니다. 선택된 Link와 상위 Polygon을 `Polygon <Polygon ID>- Link <Link ID>` 형식으로 자동 입력·저장합니다. 예: Polygon 480706169의 Link 98 → `Polygon 480706169- Link 98`.
- **버튼 템플릿**: 업무 프로그램의 로드뷰 열기 버튼 이미지 경로입니다. 민감한 화면이 포함된 템플릿은 Git에 올리지 않습니다.
- **저장 경로**: 스크린샷, 분석 이미지, JSON 결과를 저장할 상위 폴더입니다. 프로젝트 내부 상대 경로나 Windows 절대 경로를 사용할 수 있습니다.
- **이동**: 없음 / W 전진 / S 후진 중 하나를 지정하고 횟수를 설정합니다. 좌우 시점 회전은 지원하지 않습니다.
- **로드뷰 열기**: 버튼 템플릿을 찾아 클릭하고 로드뷰 창이 열릴 때까지 대기합니다.
- **화면 준비**: 캡처 또는 분석을 시작하면 입력 프로그램의 `zoom` 숫자 입력을 50으로 맞추고, 로드뷰 창을 활성화해 `Ctrl+End`로 맨 아래까지 이동합니다. 프로그램 실행과 초기 작업 설정은 사용자가 먼저 완료합니다.
- **캡처만**: 현재 시점들을 PNG로 저장하며 AI 분석은 하지 않습니다.
- **좌·우 후보 분석**: 도로 영역 마스크와 좌·우 후보 오버레이 및 JSON 보고서를 생성합니다. 이것은 회전 차로의 자동 판정이 아닙니다.
- **중지**: 다음 처리 지점에서 중지 요청을 적용합니다. AI 모델 최초 로딩/추론은 즉시 중단되지 않을 수 있습니다.
- **설정 저장**: 입력 프로그램, 로드뷰 프로그램, 검수 ID는 입력을 마치면 자동 저장됩니다. 버튼 이미지, 저장 경로, 투명도 등도 설정 저장 또는 해당 조작 시 `config.yaml`에 저장됩니다. 이 파일은 Git에서 제외됩니다.
- **투명도**: 상단 슬라이더로 제어창의 투명도를 조절합니다.
- **숨기기**: 상단 숨기기 버튼이나 `Esc`로 창을 최소화합니다.
- **결과 폴더**: 현재 검수 결과를 Windows 탐색기에서 엽니다.

## 검수 방식과 안전

검수자는 업무 프로그램의 2D 선형(하늘색 진입, 파란색 진출, 주황색 교차점 연결)과 로드뷰 캡처를 직접 대조해 좌·우회전 방향의 차로 또는 연결 도로가 보이는지 확인합니다. UI는 검수 결과를 업무 프로그램에 자동 저장하지 않습니다.

UI는 PyQt6 QThread로 작업을 백그라운드에서 실행하고, 캡처 시 UI를 잠시 숨겨 오버레이가 이미지에 섞이지 않도록 합니다. 자동화 모듈은 Qt 창이 생성된 뒤 불러와 Windows DPI 초기화 충돌을 피합니다. PyAutoGUI FAILSAFE가 활성화되어 있으며, 화면 왼쪽 위로 마우스를 이동하면 제어 작업을 긴급 중단할 수 있습니다. 작업 중 UI를 닫으면 중지 요청과 작업 스레드 종료를 기다립니다.

결과 상태는 `possible`, `not_detected_review_required`, `not_analyzed`이며 모든 결과는 사람의 검수가 필요합니다. 도로 영역 검출은 실제 좌·우회전 차로의 존재나 합법적 회전 가능 여부를 확정할 수 없습니다.

## 알려진 제약

실제 업무 Windows 환경에서 확인 전이며, 창 제목·버튼 템플릿은 환경에 맞게 설정해야 합니다. 화면이 가려지거나 잠긴 세션에서는 캡처와 조작이 실패할 수 있습니다. AI 모델 최초 다운로드에는 네트워크와 저장 공간이 필요할 수 있습니다.
