# 개발 계획

## v0.1: 초기 골격

- [x] Windows 창 제목 탐색과 버튼 템플릿 클릭
- [x] 설정 가능한 W/S 앞뒤 이동과 순차 캡처
- [x] 선택적 SegFormer 도로 영역 분할
- [x] 좌·우 후보 ROI와 오버레이 생성
- [x] 이미지·JSON 저장, 최종 자동 판정 비활성화
- [x] Python 실행환경·개인 설정·모델·캡처 결과 .gitignore

- [ ] 표본으로 좌·우 후보 표시의 한계 확인

## v0.1 제어 UI

- [x] 별도 `UI/` PyQt6 반투명 상단 고정창
- [x] 검수 ID, 창 제목, 버튼 템플릿 경로 입력
- [x] 로드뷰 열기·캡처·분석·중지 및 W/S 방향·횟수 제어
- [x] QThread 작업, 캡처 시 UI 숨김, 상태·로그와 결과 폴더 열기
- [x] 로컬 `config.yaml` 저장 및 Git 제외
- [ ] 실제 Windows 업무 환경에서 동작 확인

## v0.2: 검수 흐름과 결과 정리

- [ ] 캡처별 전진/후진 순서와 위치가 명확한 파일명·보고서로 남도록 개선
- [ ] 사람이 좌·우회전 차로/연결 도로를 표시할 수 있는 검수 상태 추가
- [ ] 가림·시야 부족·애매한 경우를 별도 보류 상태로 기록
- [ ] 업무 표본으로 오탐·미탐과 이동 간격을 검토

## v0.3: 보조 인식 개선

- [ ] 앞뒤 연속 프레임에서 도로의 좌·우 영역을 더 일관되게 추적
- [ ] 주차장·본선 확장부와 교차로 연결부 후보를 구분할 수 있는지 평가
- [ ] 가장 유용한 증거 프레임을 제안하되 자동 확정은 하지 않음
- [ ] 2D 선형 자동 추출은 표본과 필요성이 확인된 뒤 별도 설계

- [ ] 창/버튼 인식 실패와 사용자 중지 상황의 복구 확인

- [ ] 캡처 데이터 권한, 개인정보, 보관 및 라이선스 확인
