## M5. 현장 테스트 기반 지속 개선

사용자가 **진입 전·좌·직·우를 하나씩 테스트**하며 추가 판정 기준·예외·오류가 나오면 [REQUIREMENTS.md](REQUIREMENTS.md)에 반영한다. 요구가 컨셉 자체를 바꾸면 [PROJECT_CONCEPT.md](PROJECT_CONCEPT.md)도 함께 업데이트한다. **코드 변경 시 관련 디자인 문서도 반드시 갱신한다.**

**자동 테스트 코드나 테스트 실행은 사용자 요청이 있을 때만 진행한다.** 현장 검증을 수행하지 않은 기능의 정확도를 보장한다고 작성하지 않는다.
